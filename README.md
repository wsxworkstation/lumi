# 微光 Lumi 示范版

这是学生学习记录系统的第一份可点击示范版。全部内置学生与成绩均为虚构数据。

## 打开方法

双击 `打开微光.cmd`。系统会启动本地服务并打开浏览器。使用期间请保留显示 `Lumi ready` 的命令窗口；关闭该窗口会停止本地服务。

如果浏览器没有自动打开，请访问：`http://127.0.0.1:4173`

## 可以试用的功能

- 2027 年两个示范班级及中英文切换。
- 首页的欠交功课、成绩趋势、目标和提醒。
- 新增及归档班级，新增、编辑、退班及归档学生。
- 一人加入多个班，旧记录固定保留在原班。
- 新增功课、学校考试、补习考试和小考。
- 全班快速录入状态、原始分数和备注。
- 从 Excel 复制一列分数后批量粘贴。
- 在“Excel 导入”页面下载标准 `.xlsx` Template。
- 上传 Template 后先预览新增、更新和错误数量，再确认导入。
- 支持日常 `Quick_成绩` 导入，以及 Students、Classes、Enrollments、Records、Results、Goals 完整旧资料搬迁。
- 导入前保存本地快照，可以撤销上一次成功导入。
- 区分未记录、未交、迟交、补交和考试缺席。
- 修改历史、回收站与恢复。
- 学生个人趋势、同场排名、班级比较、两个学期比较、目标与老师评语。
- 单次记录导出 CSV，以及全部本地数据导出／恢复 JSON。
- 电脑、平板和手机响应式布局。

## 当前数据保存方式

示范版只把资料保存在当前浏览器的本地存储中。清除浏览器资料可能会删除记录，因此请使用测试资料，并可在“设置 → 本地数据”下载 JSON 备份。

目前尚未连接 Supabase，也没有真实账号、学生登录或云端备份。Excel 导入当前只接受系统提供的 Template；其他旧 Excel 的自由栏位配对功能尚未加入。正式开发时会把资料接入真实数据库，并在服务端实行学生只读权限。

## Excel 导入方法

1. 打开左侧“Excel 导入”。
2. 下载 `微光-Excel导入模板.xlsx`。
3. 日常导入填写 `Quick_成绩`；第一次搬迁旧资料则填写完整资料页。两种方式不要同时填写。
4. 上传 `.xlsx`，先查看错误和资料数量。
5. 没有错误后才按“确认导入”。

`student_code`、`class_code` 和 `record_code` 是稳定编号。相同学生编号会配对现有学生，相同班级编号会配对现有班级。班级页面会显示 `class_code`，学生页面已有 `student_code`。

## 目前采用的示范规则

- 补交会提高完成率，但不会提高准时率；原状态保留在修改历史。
- 考试先转换为百分比，学校与补习考试分别等权平均；小考不计入学期平均。
- 缺席和空白不会当成零分，真实的零分仍然保留。
- 同场考试并列排名采用 `1、2、2、4`。
- 第一学期暂定为 1–6 月，提醒线暂定为低于 50%、连续两次下降、连续三次未交，均可在设置修改。
